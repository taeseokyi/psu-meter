1:1 인쇄 템플릿

100 % 배율로 인쇄해서 바닥판에 붙이거나 각도 게이지로 잘라 쓰십시오. 글로 된 조립 절차는 저장소의 HOBBY_BUILD.md 에 있습니다.

인쇄 전에

브라우저 인쇄 대화상자에서 배율을 100 %(“맞춤” 아님)로, 용지를 A4 가로로 두십시오. 아래 §1 의 100 mm 자를 실제 자로 재서 확인한 뒤 쓰십시오.

1. 배율 확인

이 자가 정확히 100 mm 면 나머지 도면도 1:1 입니다

2. 각도 게이지 15.37°

잘라서 팔 덕트를 붙일 때 각도 자로 씁니다

팔이 측정면에서 아래로 15.37° 기울어야 합니다. 두 팔 사이각은 149.26°. 아래 삼각형을 오려 허브의 접착 패드에 대고 덕트를 맞추십시오.

3. 허브 주변 1:1 도면

인쇄한 허브를 얹어 대조하고, 받침대 위치를 잡습니다

가장 틀리기 쉬운 곳

외부 광선은 측정점을 지나지 않습니다. 곡면에서 꺾이기 때문입니다. 측정점(M)에서 15.37° 를 그으면 틀립니다 — 팔 축은 곡면 통과점 (22.4, 11.0) 을 지나는 직선입니다. 아래 도면의 점선을 보십시오.

4. 전체 배치

축소도 1:2.5 — 치수 숫자만 읽으십시오. 이 도면은 1:1 이 아닙니다

5. 잊으면 실패하는 다섯 가지

왜 그런지 알고 싶으면 1·3번(검게 칠하기, 확산광)은 그냥 조립 팁이 아니라 측정 원리에서 나오는 요구입니다. 슬릿과 부채꼴 §0 과 그림자 경계의 정체 를 보면 왜 타협할 수 없는지 알 수 있습니다.
  1. 내부를 전부 무광 검정으로. 미광이 경계 대비를 죽입니다. 다이소 락카 한 통이 이 프로젝트에서 가장 값진 광학 부품입니다
  2. 팔 안에 조리개 2~3개. 비용 0, 효과 큼
  3. LED 돔을 사포로 갈고 유산지를 대십시오. 집광형 LED 는 경계 자체를 만들지 못합니다 — 여러 각도가 동시에 필요하기 때문입니다
  4. TSL1401 의 광각 렌즈를 제거. 붙어 있으면 각도 분포가 뭉개집니다
  5. 화소열 128개를 두 팔이 이루는 평면 안에. 90° 틀어지면 신호가 없습니다
